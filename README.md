# 에그쿠커 마인크래프트 서버

친구용 배포 저장소. GitHub Pages로 웹 안내 페이지가 호스팅됨, 모드팩(.mrpack)은 Releases에 올림.

- **웹 안내 페이지**: https://ssubbb.github.io/egg-cooker-minecraft/
- **모드팩 다운로드**: [Releases](../../releases) 참고 (파일 올라오면 여기서 받으면 됨)

## 이 저장소 구조
- `index.html` — 친구용 접속·모드 사용법 안내 웹페이지 (GitHub Pages로 서빙됨)
- Releases — `.mrpack` 모드팩 파일

## 편집하려면
`index.html`을 직접 수정하고 push하면 Pages가 자동으로 다시 배포됨. 협업자로 초대된 사람은 누구나 수정 가능.
